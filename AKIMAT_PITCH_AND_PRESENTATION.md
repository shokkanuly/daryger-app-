## 🏗️ Technical Architecture Solution Overview

The **Daryger** system architecture was engineered specifically for regional scalability, high reliability under adverse networking conditions, and automated clinical triage:

```
                  ┌─────────────────────────────────────────┐
                  │          Patient & Doctor Web App       │
                  │   (Next.js 16, React, Tailwind CSS 4)   │
                  └────────────────────┬────────────────────┘
                                       │
                ┌──────────────────────┴──────────────────────┐
                ▼                                             ▼
  ┌───────────────────────────┐                 ┌───────────────────────────┐
  │   AI Clinical Triage      │                 │  Real-Time Consultation   │
  │ - Gemini 2.5 Flash API    │                 │ - Daily.co WebRTC Video   │
  │ - Local Fallback Engine   │                 │ - Low-Bandwidth Text Chat │
  │ - Urgency Classifier      │                 │ - Browser PDF Generator   │
  └─────────────┬─────────────┘                 └─────────────┬─────────────┘
                │                                             │
                └──────────────────────┬──────────────────────┘
                                       ▼
  ┌─────────────────────────────────────────────────────────────────────────┐
  │                        Backend Core & API Services                      │
  │  - PostgreSQL (Prisma ORM): Users, Consultations, Queues, Audit Logs  │
  │  - Redis + BullMQ: Background Job Queue for Async Tasks                │
  │  - FastAPI Microservice: MedPartners Document Parser (Docling/OCR)     │
  │  - S3 Storage (MinIO): Price Catalog & Medical Attachments              │
  └─────────────────────────────────────────────────────────────────────────┘
```

### Why this Architecture?
1. **Hybrid AI Engine**: Combines cloud AI (Gemini 2.5 Flash) for nuanced medical questionnaire analysis with a **local deterministic rule engine**. If the internet drops or cloud API latency spikes in remote areas, the system seamlessly degrades to local rules without crashing.
2. **Text-First Telehealth**: Minimizes bandwidth requirements. Video is activated on-demand, while core triage, diagnosis, and prescription issuance run over hyper-lightweight JSON payloads.
3. **Stateless Service Parsing**: Medical price lists and clinic partner catalogs are parsed asynchronously using python microservices (`pdfplumber`, `python-docx`, `openpyxl`, `Docling` ML layout), keeping the main web server fast and responsive.

1. **Phase 1 (Month 1):** Deployment in 2 pilot districts (Shakhtinsk & Saran) connected to Karaganda Regional Clinical Hospital.
2. **Phase 2 (Month 2):** Onboarding of 50 regional GPs & specialists; public awareness campaign in district polyclinics.
